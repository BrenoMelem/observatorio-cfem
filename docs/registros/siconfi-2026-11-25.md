## O que não foi verificado

- Os workflows `coletar-siconfi.yml` e a mudança em `coletar-cfem.yml` não rodaram no GitHub: `schedule` e `workflow_dispatch` só valem a partir da `main`. Os passos foram simulados localmente (a coleta e a API acima); o `tar` e a criação da Release, não.
- O tempo de uma coleta no GitHub Actions não foi medido; localmente foram cerca de 8 minutos, e uma tentativa anterior foi bem mais lenta (a API do SICONFI varia).
- A causa de cada divergência entre DCA, RREO e MSC não foi investigada; o relatório lista até 20 linhas divergentes por caso.
- `--somente-se-mudou` foi testado só com dados de teste, não contra o extrato real em duas datas.
- A divisão da despesa por função entre as dimensões continua como estava no código (nas quatro dimensões), embora a RN-ENT-12 a deixe inteira na econômica e a divisão esteja em aberto (`pendencias.md` §4).
